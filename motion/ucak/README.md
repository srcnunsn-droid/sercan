# Uçak düşüş sahnesi (15 sn, dikey)

- `ucak_dusus_15s.mp4`: 1080×1920, 30 fps, H.264 + AAC stereo, 15.00 sn
- `plane.html`: sahne (uçak, bulutlar, göktaşı, alev/duman/kıvılcım parçacık sistemi, kamera)
- `render.js`: 450 kareyi PNG olarak alır (`node render.js`)
- `audio.py`: ses tasarımı: rüzgâr, motor, göktaşı, çarpma, alev, alarm, müzik (`python3 audio.py`)
