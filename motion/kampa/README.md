# KAMPA – Hydroo MXO 35/3.0 reklamı (15 sn, dikey)

- `kampa_hydroo_reklam_15s.mp4`: 1080×1920, 30 fps, H.264 + AAC stereo, 15.00 sn
- `kampa.html`: animasyon (fontlar `../fonts/` klasöründen)
- `pump.png`, `logo.png`: verilen görsellerden arka planı temizlenmiş sürümler
- `render.js`: 450 kareyi PNG olarak alır (`node render.js`)
- `audio.py`: müzik ve ses efektleri (`python3 audio.py`)

Fiyat ve kampanya bilgileri ürün sayfası ekran görüntüsünden alınmıştır; değişirse `kampa.html` içindeki `s4` fonksiyonundan güncellenir.
